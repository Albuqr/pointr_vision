# Phase 00: Foundations

## Goal
A repository where every later layer can be built, tested and reviewed the same way.

## Scope
- Repo layout from `ARCHITECTURE.md` section 3 (empty packages with `__init__.py`).
- `pyproject.toml`: Python 3.11+, ruff config, pytest config, package `services`.
- `.gitignore`: `.venv/`, `sessions/`, `*.mp4`, `*.mov`, `pointr.db`, caches, `.jupyter_runtime/`.
- `types.py` in each edge layer (`capture`, `perception`, `session`, `recording`): the
  dataclasses and Protocols from `ARCHITECTURE.md` section 4, no implementations (D-008).
- `contracts/`: JSON Schemas for `session.json` and `run.json` (v0.1.0, superseded by
  0.2.0 in D-006) and a test that validates example files against them.
- Synthetic fixtures in `tests/fixtures/`: a short generated clip (moving coloured
  rectangles, no people), a black clip, a frozen clip. Generated by a script, committed
  script only, clips created at test time.
- `DECISIONS.md` seeded with D-001 to D-004.
- `docs/BACKLOG.md` empty with a header.
- `.claude/agents/` reviewer definitions (already written).

## Out of scope
Any computer vision code, camera access, model download.

## Dependencies allowed
`pytest`, `ruff`, `jsonschema`, `numpy`, `opencv-python`.

## Acceptance
| # | Criterion | Test |
|---|---|---|
| A1 | `ruff check .` and `pytest` pass on a clean clone | manual: scripted clean clone (no CI in phase scope) |
| A2 | Example `session.json`/`run.json` validate against schemas; a broken example fails | `tests/test_contracts.py` |
| A3 | Fixture script generates the three clips and OpenCV can read them | `tests/test_fixtures.py` |
| A4 | Protocols importable; a dummy class satisfying each passes `isinstance` with `runtime_checkable` | `tests/test_interfaces.py` |

## Gate reviewers
`code-reviewer`, `test-auditor`, `contract-guardian`.
